# Ponytail Coding Discipline

Ponytail is the anti-bloat engineering ladder for YORD:

1. **YAGNI First:** You Aren't Gonna Need It. Delete dead code, unused parameters, and speculative abstractions before they get committed.
2. **Standard Library Second:** Prefer built-in Python stdlib and native Rust std over external dependencies.
3. **One-Liners & Declarative Control:** Use list comprehensions, generator expressions, and pattern matching over verbose loops.
4. **Minimum Viable Code:** Every line must serve an active requirement. Zero fluff, zero placeholder functions.
5. **RAM Discipline:** Hardware limits are absolute. Memory must be bounded by mmap arrays, streaming iterators, and proactive garbage collection.
